# taller — marketplace de plugins de Claude Code

| Plugin | Descripción |
|---|---|
| [presenta-en-ingles](plugins/presenta-en-ingles) | Coach para preparar y ensayar en inglés la presentación de resultados anuales de una organización. |

## Instalación

Dentro de Claude Code:

```
/plugin marketplace add <tu-usuario>/taller
/plugin install presenta-en-ingles@taller
```
